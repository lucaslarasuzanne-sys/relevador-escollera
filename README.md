# Relevador · Escollera Data

Página para relevar en la calle desde el celular, sin conexión. **No tiene datos:** las zonas se cargan desde un archivo que arma el panel de Escollera Data («Llevar a la calle»), y lo relevado queda en el teléfono hasta que se exporta.

- No se conecta a ningún servidor (la política de contenido de la página lo prohíbe).
- Lo cargado se guarda en el teléfono al instante; «Exportar relevamiento» arma un archivo para pasar a la PC e importar en el panel.

Esta carpeta es una copia de `relevador/` del panel, que lo arma con `herramientas/armar-relevador.js`. No se edita a mano: para cambiarlo, se cambia el panel y se vuelve a copiar.
